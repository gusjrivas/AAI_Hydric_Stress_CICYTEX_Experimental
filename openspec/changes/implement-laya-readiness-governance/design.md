# One small terminal decision boundary

## Authority and pure government

Add one `evaluation_readiness.py` module. Public evaluation accepts one exact
issued PR43 evidence object, no mappings/flags/threshold overrides. Revalidate
its private protocol/receipts/aggregate commitments before using it and before
emission. Missing or tampered evidence fails privately; it is not a valid BLOCKED
decision. Do not weaken PR43 or the legacy HTTP readiness APIs.

A private pure helper implements the decision table and has no evidence-issuing
power. Prerequisites are VERIFIED, UNAVAILABLE or FIXTURE_ONLY; scientific
criteria are PASS, FAIL or NOT_EVALUATED. A conclusive authoritative FAIL yields
FAIL even if other prerequisites remain missing. Otherwise any missing/fixture
prerequisite or incomplete criterion yields BLOCKED. Only all VERIFIED and all
PASS yields PASS. Validate closed names, coverage, duplicate entries, exact
types and contradictory availability rather than accepting an empty conjunction.

Numerical diagnostics have a separate mechanical state. A fixture FAIL does not
become a scientific FAIL; a fixture PASS cannot authorize shadow. The helper's
hypothetical VERIFIED tests are arithmetic truth-table fixtures, not admissions.
There is no public constructor/grant for real scientific authority in this change.

## Frozen criteria and explicit availability

Use the exact issued preregistration's legacy policy/ten thresholds and four Holm
hypotheses; preserve inclusive threshold semantics. Minimum confidence 0.85 is
the frozen policy configuration, not a fabricated mean confidence metric.
Coverage, accuracy, selective accuracy, macro-F1 and mean cost use PR43's labeled
uncalibrated policy diagnostics. The site F1 gate evaluates every required site,
not a pooled replacement. Brier is probability-based and available descriptively.
Raw ECE can be compared as a labeled raw diagnostic ONLY: abstention changes the
outcome used by legacy policy ECE, so do not silently rename raw ECE as a measured
calibrated/policy ECE. Real output-stage/calibration admission remains missing.
Holm is a separate all-four criterion; descriptive intervals never replace it.

Per-example p95 latency is NOT_EVALUATED/UNAVAILABLE, never 0, NaN or bootstrap/
batch timing. Calibration and real corpus/custody, baseline and analysis-profile
admissions remain unavailable. Do not infer supply/scientific attestations from
an object called a fixture or from a digest/name alone.

The exact current evidence can therefore produce a report of checked mechanical
criteria plus scientific NOT_EVALUATED criteria and explicit prerequisites; its
overall decision is BLOCKED. No new scientific methods or experimental runs.

## Privacy, integrity and closure

Return a small immutable terminal report, bound privately to its exact statistics
parent. Public canonical serialization exposes only schema, decision, fixed policy/
fixture-profile identity, closed prerequisite/criterion/reason codes and claims;
no corpus/group/example IDs, comments, labels, rows, probabilities, response bytes
or private parent/receipt/digest references. Errors have generic messages without
cause/context leakage. Reject cloned/tampered terminal authority or mutated parent
on reuse. At most one small terminal issuance boundary, no helper registries.

No IO, inference, baseline producer, bootstrap or fit is invoked. Production
permission stays false for every state. Scientific sufficiency and shadow review
eligibility require actual authoritative PASS, never a fixture truth-table result.
Independent critic/auditor and exact-head full CI govern publication/merge; no
agent impersonates human approval. Final documentation must report remaining
scientific BLOCKED status and conditional PR45+ accurately.
